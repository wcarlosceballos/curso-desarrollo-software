⚙️ M9 · Backend y API

Sales de este módulo con un sistema que funciona de extremo a extremo: alguien hace clic en tu pantalla, la información viaja a un servidor, se guarda en la base de datos y vuelve. Y puedes explicar qué es un endpoint.

Hasta aquí tu interfaz y tus datos vivían en el mismo lugar: todo pasaba en el navegador de la persona. Eso no sobrevive al mundo real. Si dos personas registran datos al mismo tiempo, una pisa a la otra. Y nadie más puede consultar esa información, porque vive en el localStorage de un computador que no es el tuyo.

El backend es la parte que no se ve y que hace que todo lo demás sea serio: centraliza las reglas, guarda los datos donde todos los ven y deja expuesta una forma ordenada de consultarlos. Vas a elegir un framework, no tres. El primero que aprendas bien te sirve más que tres a medias.

Qué vas a aprender

  • Un framework backend: Django (Python), Express (JavaScript) o Spring (Java). El que ya conoces, o el que te sea más fácil de instalar.
  • Rutas: cada endpoint es una dirección que responde a una petición.
  • Controladores o vistas: el código que recibe la petición, aplica la regla y devuelve la respuesta.
  • Conexión con la base de datos: lo que hiciste en el M6, ahora desde el servidor.
  • Autenticación básica: quién entra, y qué puede ver cada quien.
  • API REST y JSON: la forma en que dos sistemas se hablan sin acoplarse directamente.
GET /api/ordenes          -> lista todas las órdenes
GET /api/ordenes/42       -> una sola orden
POST /api/ordenes         -> crea una orden
DELETE /api/ordenes/42    -> la elimina
MétodoSignifica
GETQuiero leer. No cambia nada.
POSTQuiero crear algo nuevo.
PUT / PATCHQuiero modificar lo que ya existe
DELETEQuiero eliminarlo

Recursos gratuitos

  • roadmaps.sh · Backend — una ruta visual para no perderte. Ignora el orden: úsalo para ubicarte.
  • Django Girls Guide (español) — tutorial de Django completo y gratuito, con ejercicios.
  • httpbin.org — un servicio público para probar peticiones y ver qué devuelve cada método.
  • Documentación oficial de Django — docs.python.org y docs de Node.js son las fuentes que no fallan.

La documentación oficial está en inglés

Vas a leer inglés técnico aunque no quieras. No hay forma de evitarlo: la documentación buena está casi siempre en inglés y a veces se demora meses en traducirse. La estrategia que funciona es traducir los términos, no el documento entero. Lee "endpoint", "route", "middleware" como palabras sueltas y síguele el sentido por el contexto. Ese inglés técnico no se aprende de otra forma: se vuelve tuyo después de dos semanas de leerlo todos los días.

Y una advertencia práctica: python manage.py runserver o npm start levantan el servidor solo en tu computador. En el M10 eso cambia, y el error típico es olvidar configurar el puerto o el host para que acepte conexiones externas.
